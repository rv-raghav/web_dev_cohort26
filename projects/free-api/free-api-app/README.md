# THE FREE API APP • 探索する (EXPLORE)

A consolidated React application that integrates multiple disparate UI projects into a single, beautifully designed dashboard. This application interacts with the [FreeAPI](https://freeapi.app/) endpoints and features a striking Japanese-inspired minimalist/neo-brutalist aesthetic.

## ✨ Features

The application consists of a sidebar navigation that lets you switch between 7 distinct integrated mini-apps:

- **Jokes Viewer**: Laugh a little with randomly generated jokes and categories.
- **Meals Listing**: Discover culinary recipes and meals from around the world.
- **Products Gallery**: Browse a collection of products with an image carousel and rich metadata.
- **Quotes Application**: Get inspired by a clean feed of famous quotes.
- **Random Cat Viewer**: Fetch adorable cat pictures and read about their temperament and origins.
- **YouTube Video Listing**: A sleek UI to display YouTube video metadata and thumbnails.
- **Random Users**: Meet random generated users with detailed profiles and locations.

## 🎨 Design System

The UI was redesigned from scratch to embrace a **Japanese Neo-Brutalist** style:
- **Typography**: Utilizing `Space Grotesk` for body text and `Syne` for bold, impactful headings.
- **Colors**: A high-contrast palette featuring an off-white background (`#F4F1EA`), stark black text (`#1A1A1A`), and vibrant red accents (`#E63946`).
- **Layout**: Clean grid structures (`Bento grids`), thick defined borders, sharp edges (0px border radius), and solid drop shadows.
- **Interactions**: Subtle, smooth micro-animations on hover and active states, plus a CSS marquee for added dynamism.

## 🛠️ Technologies Used

- **React 19**
- **Vite**
- **CSS3** (Custom Neo-Brutalist Design System)
- **Lucide React** (Icons)
- **FreeAPI** (Backend Data)

## 🚀 Getting Started

1. **Clone the repository** or navigate to the project directory:
   ```bash
   cd projects/free-api/free-api-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:5173` (or whichever port Vite provides) to see the app.
